# Day 10: OSPF States, Hello Packets & Router ID Selection

---

## 1. What is an OSPF Hello Packet?
Routers running OSPF send out **Hello Packets** (using multicast address `224.0.0.5`) to discover neighbors and maintain relationships. 

### Contents of a Hello Packet:
1. **Router ID:** Highest IP address of an active interface on the router.
2. **Hello & Dead Intervals:** 
   * **Hello Interval:** Default is **10 seconds** (how often hello packets are sent).
   * **Dead Interval:** Default is **40 seconds** (time to wait before declaring a neighbor dead if no hello is received).
3. **Network Address & Subnet Mask**
4. **Area ID** (Must match for neighbors to form adjacencies, e.g., Area 0).
5. **DR/BDR Information** (Designated Router / Backup Designated Router).
6. **Authentication Protocol** (e.g., Message Digest / MD5).
7. **Stub Area Flag**

---

## 2. The 7 OSPF Adjacency States (Step-by-Step)

Before two routers can exchange routing tables, they pass through these 7 states:

1. **Down State:** 
   * Routers start sending and receiving Hello packets to discover neighbors.
2. **Init State:** 
   * Routers receive the Hello packet and verify it. 
   * Creates the **Neighbor Table**.
   * *Command to check:* `Router# show ip ospf neighbor`
3. **2-Way State:** 
   * Verifies that the neighbor relationship is successfully established (both routers see each other in their Hello packets).
4. **Ex-Start State (Exchange Start):** 
   * Election of **Master** and **Slave** relationship between routers.
   * *Master/Slave Election Rule:* Elected by highest priority. If tied, the **highest Router ID** breaks the tie.
5. **Exchange State:** 
   * Routers exchange **DBD (Database Description)** packets, which are summaries of their link-state databases.
6. **Loading State:** 
   * Routers request detailed information about routes using **LSA Packets** (LSR, LSU, LSDB, LSACK).
   * Creates the **Topology Table**.
   * *Command to check:* `Router# show ip ospf database`
7. **Full State:** 
   * Loading is complete. **Neighbors are fully synchronized.**
   * **SPF (Shortest Path First / Dijkstra) Algorithm runs**, calculating the best path and building the final **Routing Table**.
   * *Command to check:* `Router# show ip route`

---

## 3. Router ID (RID) Selection Rules

A router needs a unique identifier (Router ID) to participate in OSPF. It is chosen in this order:
1. **Manually configured** Router ID (using `router-id x.x.x.x`).
2. **Highest IP address among all active Loopback interfaces**.
3. **Highest IP address among all active physical interfaces**.

### Example (from reference diagram):
If a router has multiple interface IPs configured:
* `172.16.0.1`
* `192.168.1.150`
* `10.0.0.10`
* `192.168.10.10`

The **Router ID** will be **`192.168.1.150`** because it is the highest numerical IP address among the active interfaces.

## 4. Quick Summary of OSPF Verification Commands

| Command | Purpose |
| :--- | :--- |
| `Router# show ip ospf neighbor` | Check OSPF neighbor states (Init, 2-Way, Full). |
| `Router# show ip ospf database` | View the link-state topology database. |
| `Router# show ip route` | View the final routing table generated by SPF. |
